# Sistema de Gestión Médica

Aplicación de escritorio desarrollada en Java que permite gestionar médicos, pacientes y turnos dentro de un entorno clínico.

## 🚀 Tecnologías
- Java
- JavaFX
- SQL
- Arquitectura MVC

## 📌 Funcionalidades
- Gestión de médicos y pacientes (CRUD)
- Sistema de turnos médicos
- Generación de reportes
- Persistencia de datos en base de datos

## 🧠 Arquitectura
El proyecto está desarrollado bajo el patrón MVC (Model-View-Controller), separando lógica, interfaz y datos.
